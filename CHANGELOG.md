# CHANGELOG

## v1.0.0 - 2026-11-09

+ [Added] Real-time character chat with streaming responses, with switchable *roleplay* and *story narration* modes.
+ [Added] Desktop Buddy module: desktop character creation, sprite-sheet generation and cutting, desktop window interaction, plus the emotion/action state machine.
+ [Added] AI-assisted character authoring: tag selection → profile generation → portrait / four-view / expression / pose image generation → sprite sheet, in a multi-step flow.
+ [Added] Character card (PNG) import / export, including tavern-card parsing with embedded local assets.
+ [Added] Model management: language models (LLM), image generation models, ComfyUI workflows, and video model configuration.
+ [Added] One-click integration with the CharaGateway official model gateway, auto-syncing available models by membership tier.
+ [Added] MCP endpoint: media tasks can be submitted and collected through MCP.
+ [Added] Membership center and payments: points, quotas, subscription upgrades, and QR-code payment.
+ [Added] Task center: unified scheduling, polling, and resume for image / video generation tasks.
+ [Added] Social sharing: one-click character-card sharing to Discord, Telegram, X, Instagram, LINE, and Xiaohongshu.
+ [Added] User onboarding tour, notifications and announcements, and data export for backup.
+ [Added] Official skill preset *Character Creation Pro*.
